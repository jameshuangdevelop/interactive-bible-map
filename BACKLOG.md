# Backlog

Ideas that are deferred and not scheduled. The PO moves an item into a milestone only with the human's approval.

## Out of scope for now (brief §1)
- 3D terrain
- Offline use
- Languages other than English
- Quizzes
- Audio
- Search by verse or by person
- Any period other than the first century (the timeline is designed to extend later)
- Native iOS/Android app build (React Native Web keeps this path open)

## Data
- **Elam ("Elamites", Acts 2:9).** M3-13 removed the Elam record because no source gave its status in about AD 50. Strabo 16.1.18 even says the Elymaean king refused to be subject to the Parthian king. Add it back when a first-century source gives the status of Susiana and Elymais, and decide whether its parent is the Parthian Empire or whether it was a semi-independent kingdom (`docs/verification/M3-well-known-areas.md`).
- **Records for the areas the timeline draws that the New Testament names,** such as the Decapolis, Idumea, Iturea, Trachonitis, Abilene, Phoenicia and Lycia. In M4 they are areas on the map without a record; M4-02's research note lists them for an M6 batch (ADR-0037).

- **Images for area records** (provinces and regions such as Egypt or Cappadocia). M3.5 covers places, and Galatia and Crete as major areas; other areas have no images yet.
- **Countries in candidate labels.** ADR-0028 keeps M3-08's country-free candidate labels for now; the record's "Today" line says where the proposed sites are.
- **Hosting AI images on Cloudflare R2** if `media/ai/` grows past about 50 MB. Until then they live in the repository and deploy with the site (ADR-0029).
- **Places within Jerusalem that aren't on the map yet,** such as the Kidron Valley, which Jerusalem's About mentions. The human asked for places in the About to be links (ADR-0033); only places on the map can be. Add them, with sources, in an M6 batch.
- **Unsupported clauses in candidate support text.** M3-16's Fact-Checker found clauses in the untouched `candidates[].support` text of Bethany beyond the Jordan and Cana that no cited source states (`docs/verification/M3-longer-about.md`). A small sourced data task should fix them.
- **Older verified text cites books no one on the team could open,** such as Murphy-O'Connor's guide and Rainey and Notley's atlas (found by M3-16's Fact-Checker). Decide whether to re-source those clauses from openable sources (a question for CP3b).
- **Thin "today" paragraphs.** In some major places, the About paragraph on what a visitor sees today is short, or rests on a 1915 encyclopedia (M3-16's Fact-Checker). Refresh them from current site and museum pages in a later data pass.
- **Stops on the routes as full places.** M5's routes give each stop without a record a short stop entry, shown only on the Routes tab (ADR-0038 item 2). An M6 batch can make them full places, with photos, starting with the ports where Paul stayed, as listed in M5-02's research note.
- **Other journeys in Acts,** such as Paul's journey to Damascus (Acts 9), his visits to Jerusalem (Acts 11:30, 15:2), and the travels of Philip (Acts 8) and Peter (Acts 9–10). The Routes tab shows Paul's three journeys and his voyage to Rome, which the brief names (ADR-0038 item 1).

## Process and tooling
- **Replay tile requests in browser tests (ADR-0045).** Record the OpenFreeMap tiles the browser tests load, as a HAR file or a small PMTiles extract, and serve them locally, so that the tests stop depending on the network. That was the main cause of ADR-0036's failed CI runs.
- **Mutation testing** (e.g. Stryker) of the data validator and builders, run weekly, to show whether the tests would catch real mistakes. Most of the code is written by AI agents.
- **Lighthouse in CI as a weekly, advisory run** (median of 5). The desktop gate stays the one that counts (ADR-0034, ADR-0045).
- **Path filters,** so that a PR changing only data or only styles runs only the affected checks.
- **A small `@webkit` phone smoke project, if Safari-only layout bugs recur.** Keep PR CI on Chromium for speed; add a focused WebKit phone shard only if Safari regressions become frequent (M7-03 follow-up).
- **`route-stop` phone drag strip follow-up once route data uses `kind: "route-stop"`.** M7-03 wires `data-sheet-drag-strip="route-stop"` in `app-shell.web.tsx`, but current route data has no `route-stop` entries, so the path is unreachable in production. When route-stop data appears, add a browser test for that strip path.
- Move to Copilot cloud agent if it becomes available, and record the switch in an ADR (brief §8).
- **A time limit for CI's build job.** `.github/workflows/app.yml`'s `build` job has no `timeout-minutes`, so a stuck run waits for GitHub's 6-hour default. On 2026-10-07, three runs on `main` hung at the Playwright install, a step lean CI (ADR-0036) has since removed from the build. Add a 20-minute limit the next time the workflow changes.
- **Share border geometry across the ancient layer's stops.** Each stop file repeats the borders it draws, about 145 KB of the layer's 318 KB gzip. A shared file of border segments that each stop lists by id would win most of that back, and the budget could return to 300,000 bytes (ADR-0037, update of 2026-10-19).

## Map
- **Sophene, the first land drawn outside the empire (M5-11's research §4.7).** Three of its four sides are sourced (Strabo 11.14.2 and 12.2.1; Smith's *Dictionary*). The Fact-Checker found that the note swaps Mount Masius and the Antitaurus (verification U2). This fits the later item on civilisations around the world.
- **Tavium and the Trocmi's land belong to Galatia (M5-11's verification, item 3).** AWMC's AD 14 line follows the Halys, which leaves Tavium in `cappadocia`. The same anchor method as the Pontus line could move it.
- **The backup modern map's borders are 1:50m Natural Earth simplified to 0.25° (M5-10's verification, P7).** At high zoom they can be several kilometres off. Use finer geometry, or cap the backup's zoom.
- **Bug: some pins vanish when zoomed in (found in the human's play-test, 2026-10-13).** For some cities, Tarsus being the clearest example, the pin disappears when zoomed in and can't be clicked. It seems to affect the muted "other" pins: below zoom 6 they're small grey dots with no labels, so the major places stand out (ADR-0035). The spec says places' pins and labels win when labels collide (§2 "Ancient layer"), so a pin should never vanish. Find the cause, for example a collision with an area label such as Cilicia's, fix it, and add a test that every place stays visible and clickable at every zoom. The PO recommends a small task for it before CP5; the human decides. **Cause found (2026-10-15):** the "other" pins' symbol layer (`ibm-city-pin`, `icon-allow-overlap: false`) loses the collision with its own label, which MapLibre places first because its layer is higher. So from zoom 6, where those places get labels and full-size pins, no "other" pin is drawn or can be clicked. On the live site, centred on Lycaonia, 6 such pins draw at zoom 5.5 and none at zoom 7 or 9; letting the pins overlap brings all 6 back. **Goes away in M5-08:** the human chose names instead of pins (ADR-0043), and M5-08's tests check that Tarsus shows and can be clicked at zoom 7 and 9.
- **Grey dots that turn red when clicked are confusing (the human's play-test, 2026-10-13).** Selecting a muted "other" pin draws it as a normal red pin, so it seems to change kind. Rethink how muted pins look when selected, or whether they should be muted at all, and update the spec (§2 "Zoom tiers"). **Goes away in M5-08** with the pins (ADR-0043): the selected place's name turns accent blue instead.
- **Major civilizations around the world (the human, 2026-10-13: "It'd help readers from different countries feel more relatable and more viscerally understand the era when Bible events are taking place").** Country borders and major cities of the first century's great civilizations beyond the Roman world, such as Han China or the Parthian Empire, so readers from other countries can place the Bible's events in their own history. This is beyond the brief's map (brief §1), so it needs its own milestone, with sources for each border and city, as M4's ancient layer had.
- **Route lines against detailed water (from M5-04's verification).** The lines are checked against Natural Earth's land and lakes, which leave out small lakes and the finest coast. On the detailed basemap, from zoom 9, the storm line clips a corner of Cauda by 1.8 km, Puteoli → Rome crosses Lakes Albano and Nemi, and the Via Egnatia skirts Lakes Volvi and Koroneia (`docs/verification/M5-route-lines.md`). A finer water dataset would remove them.
- **Routes along roads (an idea from M5-04's work; not scheduled).** Where a route's stage goes by land and no road dated to the period links its stops, its line is straight (ADR-0038 item 5). Itiner-e (itiner-e.org, CC BY 4.0) dates many more Roman roads than AWMC; if the human prefers lines that follow roads after seeing the straight ones at MC9, draw those stages along Itiner-e roads it dates to the first century.
- **A place line that follows the timeline.** In M4 the panel's line, such as "City · Galilee · Roman Empire", keeps the "about AD 50" convention (ADR-0037 item 2). It could follow the timeline's year instead, for example naming Herod Antipas's tetrarchy in AD 30.
- **Egypt's label point** sits in the Eastern Desert rather than the Nile valley most readers associate with Roman Egypt (M3-13 review nit). Revisit in a sourced label-point pass.
- **Labels at the edge of the phone's opening view.** At 390 × 844 the opening fit keeps every pin on screen, but "Jerusalem +4" runs off the right edge (M7-01, found by the PO). Placing labels on the side away from the screen's edge, or padding the fit for labels, would keep them whole.
- **The modern map's speed on real hardware.** In M4-04's software-rendered benchmark, the modern map's longest main-thread task while dragging is 122–134 ms, against 68–102 ms for the ancient map, after trimming 3D buildings, road shields, one-way arrows, park outlines and runways. The human compares the two maps on their own desktop and phone at CP4. If the modern map stutters noticeably more, trim next: 2D buildings, house numbers, the separate tunnel and bridge road layers (drawn like ordinary roads), and minor road names below zoom 12.
- **Self-hosted Protomaps fallback** (M3-07's recommended option). M3 uses the VersaTiles public server as the outage-only fallback instead, because a regional Protomaps extract won't fit Cloudflare Pages' 25 MiB file limit. Hosting it on Cloudflare R2 (free up to 10 GB-month) needs an R2 bucket and a token with R2 permissions. Revisit if VersaTiles' terms change or if outages become frequent.
- **Ancient coastlines at more ports.** M4-03 draws the old shorelines of the silted gulfs at Ephesus and Miletus. The same comparison of AWMC's ancient shoreline with today's coast could be run near Caesarea Maritima, Troas, Perga, Tarsus and Corinth's ports, keeping only differences that show at zoom 10 or below.
- **Undated Roman road links.** M4-03 draws only the roads AWMC dates to our period, and the app joins breaks of up to 4 km (MC7). Longer undated pieces still leave gaps between dated roads: 25 of them, 1,423 km in all, such as 82 km north of Smyrna and 111 km in Pisidia. Draw each one once the Fact-Checker confirms from sources that it was in use in the first century (ADR-0037).
- **Colossae is no longer unexcavated.** Its location record still says it has never been excavated, but excavation has begun (Biblical Archaeology Society interview, July 2026; found by the M3.5-03 Fact-Checker). After CP3.5, a small sourced data task updates the record.
- **Flickr Commons "No restrictions" images.** Many Internet Archive book scans on Commons carry only this license, which `docs/LICENSES.md` doesn't list, so higher-resolution scans of public-domain plates can't be used (for example a 2,256 px scan of Allom's 1836 Philadelphia plate; M3.5-04). The Fact-Checker decides whether to accept it for works that are public domain by age, and if so how to record the license.
- **Region labels rank below other places' labels.** VISUAL_SPEC §2 ("Places on the map") puts empires, provinces and regions ahead of other places, but since M3 the area-label layers sit below other places' labels, so a small place such as Nain can hide "Galilee" at zooms 6 to 8 (found by the PO at CP4). Decide which order is right, then make the spec and the map agree.
