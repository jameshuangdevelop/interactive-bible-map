# M3.5-02 verification — Images batch A: Jerusalem and the Gospels

Independent verification of Phase 1 (the Research Lead's briefs) and Phase 2 (the Media Curator's photos and prompts) on `data/m3.5-images-a` at `bdbc5ef`, against the card (`docs/tasks/M3.5-02-batch-a-jerusalem-gospels.md`), ADR-0017, ADR-0020, ADR-0026, ADR-0029, `docs/LICENSES.md` and `schema/README.md`. Places: jerusalem, temple-mount, golgotha, gethsemane, mount-of-olives, bethlehem, nazareth, capernaum, sea-of-galilee, cana, jericho, bethany, bethany-beyond-the-jordan. Reviewed 2026-10-01.

**Result:** every image's license, author and file now check out against Commons, and all 13 places have 5–6 images (69 in all, up from 66). I fixed **67 findings** in the data and briefs (22 on images, 38 in briefs, 7 on prompts; listed below). **Three items stay open**; see "Open items". The most common problems were:

- **Wrong `kind`.** 21 photos of churches, gardens and riverbanks were tagged `site`. The panel labels `site` "Excavated site", so they are now `modern`.
- **Clauses their cited source does not state.** Examples: a 15-hectare platform credited to Josephus and Wikidata; "the ambition of nature" (Josephus says this about Gennesaret, not Jericho); "the tallest [tower] about eighty cubits" (Phasael was about ninety); the Garden Tomb "about 300 meters" from the Holy Sepulchre (the two Wikidata points are about 610 m apart).
- **Quotations that were not the WEB or Whiston:** Acts 2:5, Luke 2:8, John 2:6, John 11:31, Matthew 3:4, Luke 4:16 ("their synagogue" is Matthew 13:54), and Josephus's "ornament of all Galilee" (Whiston has "the security of all Galilee").
- **The PO's six image points.** All are resolved; see "PO review points".

## Method

1. **Briefs.** I read every clause of the first seven sections of all 13 briefs, against these sources:
   - **Josephus (Whiston), opened in full:** *Jewish War* 3.10.7–8, 4.8.2–3 and 5.4–5.5; *Antiquities* 15.11.1, 18.2.1, 18.2.3 and 20.9.7. I used the Project Gutenberg texts #2850 and #2848, which are the same public-domain translation as the bibliography's CCEL entries.
   - **UNESCO:** sites 1433 and 1446, opened through UNESCO's open-data API (`data.unesco.org`, dataset `whc001`), because `whc.unesco.org` returns 403 to scripts.
   - **Taylor 1998:** the abstract, on Cambridge Core (DOI 10.1017/S0028688500016465).
   - **Wikidata:** every cited item (`P625`, `P2044`, `P2046`) and the new ones I cite (Q5687 Jericho, Q1132798 Sepphoris).
   - **Pleiades:** 678231, 678272 and 678299.
   - **Scripture:** every cited verse, from the WEB snapshot (`data/reference/engwebp_vpl.txt`).

   A script checked every quoted string in the briefs against the WEB snapshot and the two Josephus texts. All of them now match.
2. **Prompts.** I read all 26 prompts against their briefs and scanned them for later buildings (domes, churches, mosques, Ottoman, Byzantine or Crusader structures). I also checked them against the card's rule of no people in the foreground, and checked that each "Keep out / keep vague" line matches the brief's "Not known" section.
3. **Images.** For every image I queried the Commons API (`imageinfo|categories`, `iiprop=url|size|extmetadata`, at most 2 titles per request). I compared each record's license with `LicenseShortName`, and also checked the author, the stored URL (query string removed), the size, the categories and the description. Where those did not settle the place, I read the file's coordinates (`prop=coordinates`). I looked at every image on the contact sheets (`sheet.js`) and at 500 px thumbnails of each replacement candidate before choosing it.
4. **Checks.** `npm run validate:data`: 0 errors and 139 warnings, the same as at `bdbc5ef`, with none for these 13 places. `npm test`: 96 of 96 pass. `npm run check:images`: 895 Commons URLs and 179 size records, all passed. `npm run fill:image-sizes`: no changes, because the new records already carry the sizes from the API.
