## Goal
Every standard place with images shows the overall feel of the place in 1–3 images that load (ADR-0029). The human: "the photos for Laodicea are really just a few stones. It's not really helpful at all."

## Scope (Media Curator)
1. Review the images of every `standard` place that has a media file (about 40). Keep each good image. Replace any that shows only stones, fragments or an inscription, unless that object is what the place is famous for, with a wide view of the place today or its excavated site. Image ids follow display order (`-01` is the lead), so renumber as needed. Don't add images just to reach 3; 1–2 strong ones are enough.
2. Correct each image's `kind` and caption where needed.
3. Places with no image today (Lystra, and the area records) stay as they are, unless a freely licensed view of the site itself turns up.
4. `npm run validate:data` and `npm run check:images` must pass. List every change in the commit body. Commit: `data(media): improve images for standard places`.

## Scope (Fact-Checker)
Check every new or changed image as M3.5-02's Phase 3 does, in `docs/verification/M3.5-images-standard.md`. Commit: `docs(verification): verify standard-place images`.

## Out of scope
Major places (M3.5-02 to M3.5-04), AI images and app code.

## Acceptance criteria
- [ ] No standard place leads with a close-up of fragments. Every image loads and has the right `kind`.
- [ ] The Fact-Checker's report has no open findings.

## Finish
Each agent follows the session protocol in its agent file; the Fact-Checker's phase ends the task. PR title: `data(media): images for standard places`.
