| | |

## Goal
Publish one AI reconstruction for each of the 31 major places, made like a historical game's establishing shot and checked against cited research (ADR-0029 §7). The human asked to keep image generation to a minimum (2026-10-01).

## Steps
1. **Fact-Checker, before any image is made:** read the chosen generator's current terms, and confirm that we may publish its images on a public site for anyone to reuse, including commercially. Decide the license we release them under (CC0 1.0 unless the terms or the law require otherwise), and the credit wording. Record both in `docs/LICENSES.md` and `ATTRIBUTION.md`, and finish the schema's AI fields with the GIS Engineer's rules from M3.5-01. Commit: `docs(licenses): rules for AI-generated reconstructions`.
2. **GIS Engineer:** add `npm run generate:ai -- <prompt-id> [--variants N]`. It reads the prompt's text from its brief (only the paragraph under the heading, never the "Keep out" checklist), calls the chosen generator's API at the largest landscape size it offers, and saves the candidates as `media/ai-incoming/<id>-rN-vK.<ext>`, a folder Git ignores. It reads the API key from a user environment variable and never prints or writes it. It also records the tool, the model, the date and the seed next to each candidate, so the published entry can cite them. Add `npm run publish:ai -- <candidate>`, which converts a candidate to WebP of at most 1,600 px wide and 400 KB at `media/ai/<id>.webp`. Commit: `feat(scripts): generate and publish AI reconstructions`.
3. **Prompts first (Media Curator, then Fact-Checker), before any image is generated:** for each major place, choose its single best view and make it the place's only prompt to generate now, `<id>-ai-01`; the other prompts stay in the brief for later. Rewrite it under the rules in `.github/agents/media-curator.agent.md`. The Fact-Checker then checks every prompt against its brief and the rules, and the curator fixes what it finds.
4. **Generate once, check, and revise only when needed:** the PO generates one image per prompt, Jerusalem first as the test of the model. The Fact-Checker views each image against its brief and lists every error, for example a later building, the wrong roofs or walls, the wrong scale, an impossible landscape, modern objects, text, or garbled hands. A place is regenerated only for a real error, and only after the prompt is revised and rechecked, at most twice. When the error is local (one building, one object), an edit of the same image (`generate:ai -- <id> --edit-from <candidate> --instruction "<fix>"`) counts as a regeneration and is preferred, because it keeps the composition. If a prompt the Fact-Checker judges good still fails, stop and report it to the PO; that is a signal to change models (ADR-0029 §7), not to keep spending.
5. **The human:** approves the final set from a contact sheet before anything is published.
6. **Media Curator:** publish each approved image with `npm run publish:ai`, and add its entry: `kind: "ai-reconstruction"`, `aiGenerated: true`, the generator, the prompt reference, the brief's source ids and a caption starting "AI-generated reconstruction of …". Commit the revised prompts too. Put a place's AI image first only if the PO agrees. Commit: `data(media): add AI reconstructions`.
7. **Fact-Checker:** a last check of the published files against their briefs. Report every prompt revision, generation, error and fix in `docs/verification/M3.5-ai-images.md`. Commit: `docs(verification): check AI reconstructions`.

## Acceptance criteria
- [ ] The license and credit for AI images are recorded, and every AI image carries the "AI-generated reconstruction" label in the app.
- [ ] Every published AI image passed the Fact-Checker's check against its brief, and the human approved it.
- [ ] No API key appears in the repository, the logs or the PR.
- [ ] `npm run validate:data`, `npm run check:images` and the app checks pass.

## Finish
Each agent follows the session protocol in its agent file; the Fact-Checker's last phase ends the task. PR title: `data(media): AI reconstructions for major places`.
